# B 空间电子战中的重要数值

- 一个太阳日为24小时，即1,440分钟。
- 一个恒星日（sidereal day）为23.9349小时，即 $1,436.094$ 分钟。
- 开普勒第三定律为 $a^{3}=C \times P^{2}$。
- $C=36,355,285 \mathrm{~km}^{3} / \min ^{2}$。
- 地球半径 $=6,371 \mathrm{~km}$。
- 地球在比例上是一个非常平滑的球体，在大多数轨道计算中可以近似为完美球体。
- 同步卫星的周期为23小时56分钟。
- 12小时轨道卫星的高度为 $20,241 \mathrm{~km}$。
- 同步轨道高度为 $35,873 \mathrm{~km}$。
- 同步卫星的轨道半长轴为 $41,759 \mathrm{~km}$。
- 从同步卫星到地平线的视距为 41,348 km。
- 从同步轨道看地球的地表宽度为 $17.38^{\circ}$。
