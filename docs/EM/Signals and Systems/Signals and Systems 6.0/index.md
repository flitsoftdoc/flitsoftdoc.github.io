# 前言

本书主要作为工程类（及相关）专业本科生的教材使用，旨在为连续时间和离散时间的信号与系统（signals and systems）提供基础入门介绍。鉴于许多工程课程将 MATLAB 作为教学工具，本书亦在附录中提供了 MATLAB 的详细介绍。本书源于作者为教授维多利亚大学（加拿大不列颠哥伦比亚省维多利亚）两门本科课程（关于连续时间信号与系统）而撰写的一套详尽讲义笔记。具体而言，最初版本的讲义是在作者于 2003 年夏季学期教授 ELEC 260（信号分析）课程时编写的，之后为教授 2003 年秋季学期的 ELEC 255（系统动力学）课程又增加了一些内容。随着时间推移，这套讲义经历了多次修订，最终演变为现在这本教材。最初的版本仅涵盖连续时间部分，后续又补充了离散时间部分的内容。上述工作最终形成了你现在所阅读的这本书。

## 教师指导建议

连续时间（Continuous-Time，CT）与离散时间（Discrete-Time，DT）信号与系统的理论被广泛教授于各类工程及相关学科中。这些内容在课程（或多学期课程）中的安排方式在不同高校或项目中可能存在显著差异。因此，本教材的组织结构设计上充分考虑了多种授课安排的适应性。可能的组织方式包括（但不限于）：

- 先讲授 CT 部分，再讲授 DT 部分的顺序呈现方式（例如，两个单学期课程，第一门涵盖 CT 部分，第二门涵盖 DT 部分）；
- 先讲授 DT 部分，再讲授 CT 部分的顺序呈现方式；
- CT 与 DT 部分融合呈现的方式（例如，一门或两门学期课程，将 CT 与 DT 内容综合讲授）。

## CT 与 DT 部分的顺序呈现方式

若采用先讲 CT 后讲 DT 的顺序讲授方式，可参考以下教材内容安排：

1. 第一门课程/学期：CT 部分  
   (a) 第1章（引言），重点讲授与 CT 相关的内容  
   (b) 若需复习复数分析：附录A（复数分析）  
   (c) 第2章（基础知识），重点讲授与 CT 相关的内容  
   (d) 第3章（连续时间信号与系统）  
   (e) 第4章（连续时间线性时不变系统）  
   (f) 第5章（连续时间傅里叶级数）  
   (g) 第6章（连续时间傅里叶变换）  
   (h) 若需介绍部分分式展开法：附录B（部分分式展开）  
   (i) 第7章（拉普拉斯变换）  

2. 第二门课程/学期：DT 部分  
   (a) 第1章（引言），重点讲授与 DT 相关的内容  
   (b) 第2章（基础知识），重点讲授与 DT 相关的内容  
   (c) 第8章（离散时间信号与系统）  
   (d) 第9章（离散时间线性时不变系统）  
   (e) 第10章（离散时间傅里叶级数）  
   (f) 第11章（离散时间傅里叶变换）  
   (g) 第12章（z变换）  

若需改为先讲 DT 后讲 CT 的顺序，可大致调换上述两门课程的顺序即可，因为本书在编排时尽量避免了 CT 与 DT 之间的依赖。然而，仍存在少量依赖关系。为解决这些依赖关系，需进行如下调整：

- 从 DT 课程中移出一小部分内容，加入 CT 课程中，即：
  - 第11.17节，介绍离散时间傅里叶变换（DTFT）与连续时间傅里叶级数（CTFS）之间的关系；
  - 第11.18节，介绍 DTFT 与连续时间傅里叶变换（CTFT）之间的关系。  
- 从 CT 课程中移出一小部分内容，加入 DT 课程中，即：
  - 第3.5.11节，介绍冲激函数（delta function）。

## 作者简介

Michael Adams 于 1993 年获得加拿大滑铁卢大学计算机工程学士学位（B.A.Sc.），1998 年获得加拿大维多利亚大学电气工程硕士学位（M.A.Sc.），2002 年获得加拿大英属哥伦比亚大学电气工程博士学位（Ph.D.）。1993 至 1995 年间，他在加拿大渥太华的贝尔北方研究所（Bell-Northern Research）担任技术人员，开发用于光纤通信系统的实时软件。自 2003 年起，他加入加拿大维多利亚大学电气与计算机工程系，历任助理教授、现任副教授。

Michael 曾获得加拿大自然科学与工程研究委员会（NSERC）研究生奖学金。他曾作为加拿大代表团成员参与 ISO/IEC JTC 1/SC 29（即音频、图像、多媒体与超媒体信息编码）的标准制定工作，并积极参与 JPEG-2000 标准制定，担任 JPEG-2000 第五部分标准的联合编辑者，并是首批 JPEG-2000 实现之一（即 JasPer）的主要作者。

他的研究兴趣包括软件、信号处理、图像/视频/音频处理与编码、多分辨率信号处理（如滤波器组与小波）、几何处理及数据压缩。
